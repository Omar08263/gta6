Sunset Streets — an open-world crime game set in Solmar Bay, a sun-soaked coastal city of our own. Explore twelve blocks of downtown towers, beachfront and marina on foot and by car, steal cars, outrun the Solmar Bay patrol under a 5-star wanted system, and run a five-job story arc as Rae "Rook" Marlow — from courier runs to the marina heist finale. Traffic and pedestrians, car chases, combat, a HUD with a live minimap, synthesized WebAudio sound, and localStorage saves. Built with three.js, static files only, zero network requests at runtime.

## Run it

node serve.ts
# then open http://localhost:8080
